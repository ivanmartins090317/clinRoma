# Apresentação · ClinRoma · Clínica Neo Roma

Material para apresentar o piloto ao **Dr. Felipe Roma**, com base no [manual do usuário](../manual-usuario/MANUAL-COMPLETO.md) e nos prints de setembro/2026.

## Como abrir

1. Abra no navegador (Chrome ou Edge recomendado):

   `docs/apresentacao-neo-roma/index.html`

   Caminho absoluto: `c:\projetos\clinroma\docs\apresentacao-neo-roma\index.html`

2. Para apresentar em tela cheia: tecla **F** ou F11 do navegador.

3. Navegação: **setas** ← →, botões na barra superior. No celular, **role a tela** para ver o slide inteiro; deslize na horizontal só no topo/fim do scroll para mudar de slide.

4. Impressão ou PDF: Ctrl+P (cada slide em uma página; oculta a barra de ferramentas).
